# SPE 다운로드

Smart Photo Editor의 **Windows 설치파일·업데이트 파일 전용 저장소**입니다.
프로그램 소스 코드는 이 저장소에 포함하지 않습니다.

## 다운로드 상태

현재 추가 환자 자료 검사에서 확인된 웹셉 기록 호환성을 보완하고 있습니다. 0.31 후보의 공개 다운로드 검증은 통과했지만, 보완 전 자동 설치 경로에는 연결하지 않았습니다. 후보 파일은 검증용으로 보존했으며 공개 설치본은 준비 후 [Releases](https://github.com/KwanghyoChoi/SPE-Releases/releases)에 제공합니다.

공개 설치본이 준비되면 릴리스의 **SPE_Install.exe**로 설치할 수 있습니다. 설치 도구는 공개 설치본을 다운로드하고 서명된 배포 정보·파일을 확인합니다. GitHub의 `Source code` ZIP은 앱 설치파일이 아닙니다.

## 이용 안내

- 사진 인식·분류·편집, 덴트웹·웹셉 전송, 지정 폴더의 매일 자동 실행을 지원합니다.
- 설치 자체로 체험이 시작되지 않습니다. 앱에서 시작한 최초 체험 기간은 14일입니다.
- 계속 이용하려면 라이선스가 필요하며 라이선스 1개는 PC 1대에 연결됩니다.
- 환자 사진·차트번호·개인정보·비밀번호·라이선스 코드를 이 저장소에 올리지 마세요.
- 문의: kwanghyo.choi@gmail.com

확인되지 않은 신원·촬영 세트·전송 결과는 확인 대기로 남습니다. 자세한 검증 상태와 다운로드 파일은 각 릴리스 설명을 확인해 주세요.
