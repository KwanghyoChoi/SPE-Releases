# SPE 다운로드

Smart Photo Editor의 **Windows 설치파일·업데이트 파일 전용 저장소**입니다.
프로그램 소스 코드는 이 저장소에 포함하지 않습니다.

## 다운로드 상태

[SPE 0.31.0 공개 검증 후보](https://github.com/KwanghyoChoi/SPE-Releases/releases/tag/v0.31.0)를 제공합니다. 실제 설치·예약 실행 및 추가 사진 검증이 진행 중인 사전 공개본이며, 진료용 정식 배포 완료를 뜻하지 않습니다.

처음 설치할 때는 릴리스의 **SPE_Install.exe**를 내려받아 실행하세요. 공개 설치본을 다운로드하고 서명된 배포 정보·파일을 확인합니다. 전체 파일이 필요한 경우 릴리스의 Windows ZIP을 이용할 수 있습니다. GitHub의 `Source code` ZIP은 앱 설치파일이 아닙니다.

## 이용 안내

- 사진 인식·분류·편집, 덴트웹·웹셉 전송, 지정 폴더의 매일 자동 실행을 지원합니다.
- 설치 자체로 체험이 시작되지 않습니다. 앱에서 시작한 최초 체험 기간은 14일입니다.
- 계속 이용하려면 라이선스가 필요하며 라이선스 1개는 PC 1대에 연결됩니다.
- 환자 사진·차트번호·개인정보·비밀번호·라이선스 코드를 이 저장소에 올리지 마세요.

확인되지 않은 신원·촬영 세트·전송 결과는 확인 대기로 남습니다. 자세한 검증 상태와 다운로드 파일은 각 릴리스 설명을 확인해 주세요.
