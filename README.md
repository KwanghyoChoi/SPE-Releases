# SPE 다운로드

Smart Photo Editor의 **Windows 설치파일·업데이트 파일 전용** 저장소입니다.
프로그램 소스 코드는 이 저장소에 포함하지 않습니다.

## 다운로드 상태

현재 실사용 검증과 재배포 확인을 진행 중이며, 아직 공개 설치파일은 없습니다.
준비가 끝나면 [Releases](https://github.com/KwanghyoChoi/SPE-Releases/releases)에서 제공합니다.

## 이용 안내

- 최초 체험 기간은 14일입니다.
- 계속 이용하려면 라이선스가 필요하며, 라이선스 1개는 PC 1대에 연결됩니다.
- 환자 사진·차트번호·개인정보·비밀번호·라이선스 코드를 이 저장소에 올리지 마세요.
- 문의: kwanghyo.choi@gmail.com

설치파일이 공개되기 전의 내부 검증 후보는 진료용 정식 배포본이 아닙니다.
