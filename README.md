# SPE 다운로드

Smart Photo Editor의 **Windows 설치파일·업데이트 파일 전용 저장소**입니다.
프로그램 소스 코드는 이 저장소에 포함하지 않습니다.

## 다운로드 상태

**0.39.0 공개 검수용 버전(prerelease)**을 게시했습니다. 치아와 사진을 결합한 새 앱 아이콘을 실행파일과 설치창에 반영했습니다. 사진 편집·전송·매일 예약·라이선스 동작은 변경하지 않았으며, 긴 웹셉 기록 호환성 보완도 유지합니다. 공개 ZIP의 비로그인 전체 다운로드·해시 대조, Windows 정상 온라인 설치·최종 성공 화면·안정 실행기·네 탭과 보존된 결과창 표시를 확인했습니다. 실제 예약 후 결과창 자동 표시는 직전0.38에서 확인했으며,0.39의 기존 기록 열람을 새 예약 실행으로 주장하지 않습니다. 원본·전송 기록·이용권·기존 설정은 보존했습니다. 신규 실제 X-ray 왕복과 병원별 환경 인수는 아직 남아 있어 전체 임상 검수 완료판으로 안내하지 않습니다.

[SPE_Install.exe 다운로드](https://github.com/KwanghyoChoi/SPE-Releases/releases/download/v0.39.0/SPE_Install.exe) · [0.39.0 검증 상태와 파일](https://github.com/KwanghyoChoi/SPE-Releases/releases/tag/v0.39.0)

**SPE_Install.exe**를 실행하고 설치 시작을 누르세요. 설치 도구가 약 1.0 GB의 공개 설치본을 내려받아 서명된 배포 정보·파일·실행 환경을 검증합니다. 다운로드 100% 뒤에도 파일·실행기 검증 시간이 필요하므로 최종 설치 확인 문구가 나올 때까지 기다리세요. 기존 아너스 진료용 앱과 원본 사진은 변경하지 않습니다. GitHub의 `Source code` ZIP은 앱 설치파일이 아닙니다.

현재 EXE에는 Windows Authenticode 게시자 서명이 없습니다. 배포 정보의 전자서명 검증과 Windows 게시자 서명은 별개입니다. Windows가 실행을 차단하면 출처 확인 없이 보호 기능을 해제하지 말고 문의해 주세요.

## 이용 안내

- 사진 인식·분류·편집, 덴트웹·웹셉 전송, 지정 폴더의 매일 자동 실행을 지원합니다.
- 설치 자체로 체험이 시작되지 않습니다. 앱에서 시작한 최초 체험 기간은 14일입니다.
- 계속 이용하려면 라이선스가 필요하며 라이선스 1개는 PC 1대에 연결됩니다.
- 환자 사진·차트번호·개인정보·비밀번호·라이선스 코드를 이 저장소에 올리지 마세요.
